# activity-browser

Activity Browser is open source LCA software with a desktop graphical interface, built
on Brightway. It lets a practitioner browse projects and databases, edit activities and
exchanges, set up and run calculations and read the results without writing Python
(source: activity-browser-repo).

The project describes itself as a productivity tool for Brightway rather than a
replacement for it: you can model in Python and look at the result in the interface, or
the other way round. Its highlights are calculations across several reference flows,
impact categories and scenarios; parameters, prospective scenario databases and
uncertainty; contribution analysis, Sankey diagrams, Monte Carlo and global sensitivity
analysis; and a plugin mechanism (source: activity-browser-repo).

**Two lines are current on 2026-09-21.** The stable line is 2.11.2 on conda-forge,
built on Brightway 2 (source: activity-browser-conda-forge). The 3.0 line is an open
beta, published only as pre-releases, and uses Brightway 2.5 with multifunctionality
support (source: pypi-activity-browser, activity-browser-repo). Choose deliberately;
see [status.md](status.md) and [gotchas.md](gotchas.md).

## Install

The supported route is conda, which is what the README and the bundled installation
guide both document (source: activity-browser-repo):

```bash
conda create -n ab -c conda-forge activity-browser
conda activate ab
activity-browser
```

That installs the stable line. The 3.0 beta is on PyPI only, as a pre-release, so pip
will not select it without being asked:

```bash
pip install --pre activity-browser
```

## What it does

- **Manages projects and databases.** Project setup, database creation and import
  wizards. See [commands.md](commands.md).
- **Edits the inventory.** Activities, exchanges, parameters and uncertainty, in
  tables. See [layout.md](layout.md).
- **Runs calculations.** Calculation setups across several reference flows, impact
  categories and scenarios. See [classes.md](classes.md).
- **Analyses results.** Contributions, Sankey and graph explorer, Monte Carlo and
  global sensitivity analysis. See [classes.md](classes.md).
- **Extends through plugins.** A documented plugin base class and a plugin manager
  wizard. See [classes.md](classes.md).

## Datasets

No inventory data is bundled. What ships with the package is interface material: icons,
stylesheets, JavaScript for the graph and Sankey views, HTML shells for those views, a
start screen, and a small database classification resource. The 3.0 tree also carries a
list of which ecoinvent versions each Activity Browser version is compatible with,
fetched from the repository at start-up with a bundled copy as fallback.
[datasets.md](datasets.md) has the detail.
