# flowmapper

`flowmapper` automates matching elementary flow lists in life cycle assessment. Given a
source list and a target list it applies a sequence of matching strategies, reports what
matched and what did not, and writes the result out as a reusable mapping file
(source: flowmapper-repo).

It assumes a small core ontology behind every flow list, whatever the serialisation:
a canonical `name`, an `identifier`, a `context` as a hierarchical tuple of
compartments, a `unit`, sector-specific labels such as a CAS number, and a list of
`synonyms`. Source and target lists must be given in that shape; flowmapper ships
extractors that produce it from ecospold2 and SimaPro files (source: flowmapper-repo).

**Version documented:** 0.4 · **obtained from:** PyPI, installed into a throwaway
environment with `uv run --with flowmapper==0.4` and introspected, with the CLI checked
against its own `--help` · **as of:** 2026-09-21

## Install

```bash
pip install flowmapper==0.4
```

## What it does

- **Matches two flow lists.** The `Flowmap` class holds the source flows, the target
  flows and the rules, and computes the crosswalk. See [classes.md](classes.md).
- **Runs from a shell.** `flowmapper map SOURCE TARGET` does the whole job and writes
  the mapping plus diagnostic files. See [commands.md](commands.md).
- **Extracts flow lists from real files.** `flowmapper extract-simapro-csv` and
  `flowmapper extract-ecospold2` turn those formats into the list shape flowmapper
  expects. See [commands.md](commands.md).
- **Writes mapping files other tools read.** Output is GLAD format, randonneur
  transformation format, or both. See [datasets.md](datasets.md).

## Datasets

flowmapper ships reference data rather than inventory data. Bundled in the wheel are a
Pint unit-alias file and a standard units harmonisation package, a SimaPro to ecoinvent
context mapping, a place-code list, a small name-and-location fixup list, and manual
matching material for SimaPro to ecoinvent pairings, including a prepared
SimaPro 2024 to ecoinvent 3.10 biosphere result. What it produces is a mapping file
plus unmatched-flow diagnostics. Neither the bundled files nor the outputs carry
inventory amounts or characterisation factors: they are name, context, unit and
identifier correspondences, with unit conversion factors where units differ.
[datasets.md](datasets.md) has the detail.
