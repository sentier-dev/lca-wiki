# randonneur

`randonneur` applies changes to life cycle inventory data from a declarative file
instead of from a one-off script. It defines a JSON data format for describing
transformations, helper functions to create and validate files in that format, and
functions that apply those transformations to a graph of nodes and edges
(source: randonneur-repo).

It is used to relink data to a newer background release, to move between the
nomenclature of one system and another, and to normalise fields such as units. It does
not have a fixed data schema: every transformation file declares its own mapping from
its labels to the accessors of the data it will be applied to. Although it was designed
for Brightway, the library itself is not Brightway specific (source: randonneur-repo).

`randonneur` ships no transformation data of its own. The data lives in the sister
package `randonneur_data`, whose registry is described in [datasets.md](datasets.md)
(source: randonneur-repo).

## Install

```bash
pip install randonneur==0.7.2
```

`randonneur_data` is a declared dependency and is installed with it; version 0.7.2 of
the data package was current on the same date (source: pypi-randonneur,
pypi-randonneur-data).

## What it does

- **Applies a transformation to a graph.** `migrate_nodes` and `migrate_edges` walk a
  list of node dictionaries and rewrite them according to a transformation dictionary.
  See [classes.md](classes.md).
- **Applies a stored transformation by name.** `migrate_edges_with_stored_data` and
  `migrate_nodes_with_stored_data` look the transformation up in the `randonneur_data`
  registry, so the caller names a migration rather than loading a file. See
  [datasets.md](datasets.md).
- **Builds new transformation files.** `create_excel_template` and `read_excel_template`
  let a domain expert do the matching in a spreadsheet, which is then read back into a
  `Datapackage`. See [classes.md](classes.md).
- **Configures matching.** `MigrationConfig` decides which fields are compared, which
  verbs run, whether matching is case sensitive, and what the edge key is called. See
  [gotchas.md](gotchas.md).

There is no command line interface; everything is called from Python. See
[commands.md](commands.md).

## Datasets

`randonneur` itself ships no inventory or mapping data. What it does ship is a set of
constants: `MappingConstants` holds ready-made label mappings for the common inventory
serialisations (ecospold1 biosphere, ecospold2, ecospold2 biosphere, ILCD biosphere and
SimaPro CSV), each an expression language plus a dictionary of field accessors. The
transformation packages themselves come from `randonneur_data`, which ships a registry
of migration files covering ecoinvent version to version moves, SimaPro to ecoinvent
nomenclature, Agribalyse and Agri-footprint fixes, and generic unit and context
normalisations. [datasets.md](datasets.md) has the detail.
