# randonneur datasets

Descriptors stay broad: no per-datapoint content and no amounts.

## Bundled label mappings (`MappingConstants`)

- **Version:** ships with randonneur 0.7.2 (2025-12-17).
- **Sectors:** none; these are format descriptions, not inventory data.
- **Provenance:** written by the randonneur maintainers as part of the package
  (source: pypi-randonneur).
- **Schema:** each constant is a dictionary with an `expression language` key (XPath,
  JSONPath or a JSONPath-like dialect) and a `labels` key mapping a randonneur field
  name to the accessor that reads it out of that serialisation.
- **Constants present in 0.7.2:** `ECOSPOLD1_BIO`, `ECOSPOLD2`, `ECOSPOLD2_BIO`,
  `ECOSPOLD2_BIO_FLOWMAPPER`, `ILCD_BIO`, `SIMAPRO_CSV`.
- **Vocabulary:** the field names randonneur matches on, such as `name`, `unit`,
  `location`, `reference product`, `context`, `uuid` and `filename`.

## The `randonneur_data` registry

`randonneur` provides no transformation data itself; `randonneur_data` does
(source: randonneur-repo).

- **Version:** randonneur_data 0.7.2, released 2025-11-21 (source: pypi-randonneur-data).
- **Contents:** 57 registered migration packages in that release, counted by listing
  `randonneur_data.Registry().keys()` in a throwaway environment.
- **Sectors:** cross-sector. The packages are about nomenclature and database releases
  rather than about an industry.
- **Provenance:** each entry declares its own `contributors` and `licenses` blocks;
  the ecoinvent version-to-version files are generated by `ecoinvent_migrate` and
  credit the ecoinvent association as author with a maintainer as wrangler, and the
  SimaPro files are provided by PRe (source: randonneur-repo).
- **Licences:** stated per package inside the file. The examples in the README and the
  entries inspected in 0.7.2 use Creative Commons Attribution 4.0. Read the `licenses`
  block of the package you actually apply rather than assuming.
- **Schema:** one JSON object per package with `name`, `description`, `contributors`,
  `created`, `version`, `licenses`, `graph_context` (`nodes`, `edges`, or both),
  `mapping` (source and target label mappings), optional `source_id` and `target_id`,
  and at least one verb key holding the list of changes.
- **Registry metadata:** the registry itself adds `filename`, `compression` and
  `case-insensitive` per entry, so a caller can see how the file is stored before
  fetching it.
- **Methods:** none. These are data transformations, not impact assessment methods.

### What the 57 packages cover

Groups present in randonneur_data 0.7.2, by the shape of their names:

| Group | What it does |
|---|---|
| `ecoinvent-<old>-biosphere-ecoinvent-<new>-biosphere` | elementary flow changes between two ecoinvent releases, including transitive files that jump several releases |
| `ecoinvent-<old>-<model>-ecoinvent-<new>-<model>` | technosphere activity changes between two ecoinvent releases of the same system model |
| `ecoinvent-<version>-biosphere-EF-<version>-biosphere` | ecoinvent elementary flows to the Environmental Footprint flow list |
| `SimaPro-<year>-ecoinvent-<version>-...` | SimaPro nomenclature to ecoinvent nomenclature, with separate manual-match files |
| `agribalyse-...`, `agrifootprint-...` | fixes specific to those databases, including deleting aggregated ecoinvent datasets and restoring SimaPro-style ecoinvent names |
| `Flowmapper-standard-units-harmonization` | unit spellings normalised, linked to the flowmapper unit handling |

### Identifier convention

Package names follow `<database name>-<version>-<optional modifier>`, agreed at
Brightcon 2022: `agribalyse-3.1.1`, `forwast-1`, `ecoinvent-3.10-cutoff`,
`simapro-9-biosphere` (source: randonneur-repo). A migration file that moves from one
release to another names both, source first.

- **Source branch:** the ecoinvent releases these files talk about are documented in
  [../../../ecoinvent/](../../../ecoinvent/). Nothing in a randonneur package carries
  an ecoinvent amount; the files carry identifiers, names and, where a unit changes, a
  conversion factor.
