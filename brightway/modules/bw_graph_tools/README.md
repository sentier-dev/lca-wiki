# bw_graph_tools

`bw_graph_tools` walks the supply chain of a solved Brightway system instead of only
reading the matrix result. Where a matrix solution answers all the equations at once,
traversal visits nodes along paths and records the impact of arriving at each node by
that path (source: bw-graph-tools-repo).

The README names three components: a graph traversal class, a function that guesses
production exchanges from datapackages alone, and a pair of functions that find the
path from one node to another carrying the largest amount of the first node's reference
product (source: bw-graph-tools-repo). Version 0.10 adds tagged traversals, which group
leaf nodes by a tag before reporting.

The reason to traverse rather than solve is that a matrix result cannot distinguish two
different paths to the same object, and cannot carry per-path information such as the
time at which a process happens. That second use is what `bw_temporalis` builds on
(source: bw-graph-tools-repo).

```bash
pip install bw_graph_tools==0.10
```

(source: bw-graph-tools-repo).

## What it does

- **Traverses a solved system.** `NewNodeEachVisitGraphTraversal` and its siblings walk
  the technosphere following the paths of greatest impact, under a settings object that
  caps the work. See [classes.md](classes.md).
- **Describes what it found.** Traversal produces `Node`, `Edge` and `Flow` records
  rather than a tree of dictionaries, so results can be tabulated directly. See
  [classes.md](classes.md).
- **Finds a path between two nodes.** `get_path_from_matrix` works on matrix indices,
  `path_as_brightway_objects` returns the exchanges. See [classes.md](classes.md).
- **Guesses production exchanges.** `guess_production_exchanges` applies heuristics to
  a mapped technosphere matrix when the datapackage does not label them. See
  [gotchas.md](gotchas.md).

## Datasets

None. `bw_graph_tools` ships no data files: the installed package is Python modules
only. It reads the matrices and datapackages another package built, and writes nothing
to disk. See [datasets.md](datasets.md).
