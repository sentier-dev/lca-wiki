# ecoinvent_interface

`ecoinvent_interface` is an unofficial and unsupported Python client for ecoinvent's own
services. A user who holds an ecoinvent licence authenticates with their own
credentials and the library downloads release files, process files and reports on their
behalf (source: ecoinvent-interface-repo).

This page documents the **access mechanics only**: what you need in order to
authenticate, what kinds of files exist, and how they are cached. No ecoinvent data,
amounts or characterisation factors appear anywhere in this wiki; the database itself
is described, structure only, in [../../../ecoinvent/](../../../ecoinvent/).

The library is deliberately low level. It has no Brightway-specific code, does no
browser interaction, and the maintainers state that extensions to fetch process LCI or
LCIA data or scores will not be accepted (source: ecoinvent-interface-repo).

**Version documented:** 3.1 · **obtained from:** PyPI, installed into a throwaway
environment with `uv run --with ecoinvent_interface==3.1` and introspected · **as of:**
2026-09-21

## Install

```bash
pip install ecoinvent_interface==3.1
```

Versions older than 3.0 stopped working in February 2025, so an environment pinned
below 3.0 will fail at authentication rather than at import
(source: ecoinvent-interface-repo).

## What you need before it works

- A current ecoinvent licence and an account with a username and a password.
- The ecoinvent licence and the personal identifying information agreement accepted on
  the ecoinvent website for that account. The library cannot do this for you, and calls
  fail until it is done (source: ecoinvent-interface-repo).

Credentials go into a `Settings` object, an environment variable pair, or a secrets
directory. [gotchas.md](gotchas.md) covers the precedence order. This wiki never
records credential values.

## What it does

- **Lists and downloads releases.** `EcoinventRelease` lists versions, lists system
  models and fetches a release of a chosen type. See [classes.md](classes.md).
- **Downloads reports and extra files.** The same class lists and fetches the PDF
  reports and the additional files published beside a release.
- **Works on single processes.** `EcoinventProcess` selects one dataset by index,
  filename or attributes and downloads its files. See [classes.md](classes.md).
- **Caches what it downloaded.** `CachedStorage` keeps a catalogue so a second run is
  offline. See [gotchas.md](gotchas.md).

## Datasets

The package itself ships one data file: a compressed set of process index mappings, one
per ecoinvent version and system model, used to turn a filename or a set of attributes
into the integer dataset index the API expects. Everything else is fetched at run time
from ecoinvent's servers and is licensed data that stays on the user's machine.
[datasets.md](datasets.md) describes the structure of both, with no content.
