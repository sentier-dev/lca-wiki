# pypardiso

`pypardiso` solves large sparse linear systems using the PARDISO solver from the Intel
oneAPI Math Kernel Library, a shared-memory parallel direct sparse solver. It provides
the same functionality as `scipy.sparse.linalg.spsolve` for `Ax = b`, and in many cases
is significantly faster than SciPy's single-threaded SuperLU
(source: pypardiso-repo).

Brightway cares because an LCA is exactly that problem: `bw2calc` warns at import on an
AMD or Intel x64 machine when pypardiso is not installed, and suggests installing it for
much faster calculations. That warning is how most people first meet this package.

It is not a binding to the separate PARDISO 7 project, and it does not support complex
numbers (source: pypardiso-repo).

**Version documented:** 0.4.7 · **obtained from:** PyPI, installed into a throwaway
environment with `uv run --with pypardiso==0.4.7` and introspected; a ten by ten sparse
solve was run successfully against MKL 2026.1.0 on x86-64 Linux · **as of:** 2026-09-21

## Install

```bash
pip install pypardiso==0.4.7
```

or, on conda:

```bash
conda install -c conda-forge pypardiso
```

The package runs on Linux and Windows. It depends on `mkl`, excluding the 2024.0
release, plus numpy and scipy (source: pypi-pypardiso). MKL is a large wheel, so
expect the install to be bigger than the package suggests.

**On macOS it is not an option.** MKL is not available on Apple silicon, and the
maintainers recommend `scikit-umfpack` instead (source: pypardiso-repo). Packages that
depend on pypardiso mark it accordingly: `bw_timex` requires it only on x86-64 Linux
and Windows (source: pypi-bw-timex). See [gotchas.md](gotchas.md).

## What it does

- **Drop-in replacement for `spsolve`.** `pypardiso.spsolve(A, b)` takes a CSR or CSC
  matrix and a vector or matrix. See [classes.md](classes.md).
- **Reusable factorisation.** `pypardiso.factorized(A)` mimics
  `scipy.sparse.linalg.factorized`. See [classes.md](classes.md).
- **Direct control of the solver.** `PyPardisoSolver` exposes the matrix type, the
  phase and the MKL `iparm` array for people who need them. See [classes.md](classes.md).

## Datasets

None. pypardiso ships three Python modules and nothing else: no data files, no
reference lists, no nomenclature. It is a numerical library and knows nothing about
LCA. See [datasets.md](datasets.md).
