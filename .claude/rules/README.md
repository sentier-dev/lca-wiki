# .claude/rules

House rules for anyone, person or agent, changing this repository. They are trimmed
copies of the rules the wiki was built under, kept short and made specific to a markdown
repository. The originals live in the maintainer's global agent configuration; these
copies are the ones that apply here.

| File | Applies to |
|---|---|
| `coding-style.md` | every page, and the one script in `scripts/` |
| `security.md` | every page, and everything about to be committed |

The content rules, which matter more here than the style rules, are in
[../../AGENTS.md](../../AGENTS.md) (tool-neutral; `CLAUDE.md` is a symlink to it)
