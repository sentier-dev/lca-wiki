# <database name> knowledge

Methodology, format, versions, licence, access route, sector coverage in GICS terms and in
the publisher's own groups, provenance, schemas, methods and vocabulary. One subject per
file, each claim carrying the publisher's own documentation as its source.

## Naming rule

`lower-case-with-hyphens.md`, one subject per file.

## How to add here

1. Cite the publisher for every claim.
2. Describe data, never copy it.
3. Add the page to `index.md` and check by hand that every link and anchor resolves.
